## Entity-Relationships

A written description of each table, what it represents, and how it relates to every other table. One paragraph per table is sufficient.

## Column definitions:

For every table: column name, data type, constraints (NOT NULL, UNIQUE, DEFAULT, CHECK), and whether it is a primary key or foreign key.

## Normalization notes:
